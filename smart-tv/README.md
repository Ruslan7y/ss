# Smart TV

Seçilen oyun uygulaması açıldığında bunu algılar (altta 1 saniyelik "+"), her yeni turda ekran görüntüsünü
kendiliğinden alır (altta "0"), Gemini'ye sorar ve cevabı ülke adının ilk iki harfi olarak ekranın altında gösterir.
Ortadaki görünmez alana 3 kez dokunarak elle de çalıştırılabilir.

APK: GitHub Actions → "Smart TV APK" → Artifacts → SmartTV-APK.
