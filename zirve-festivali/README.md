# Zirve Festivali

İki haritada (Dağ Yolu, Çöl Şehri) iki gerçekçi arabayla (Kızıl Ok, Nova Konsept) sürüş oyunu.
Modlar: Serbest Sürüş, Kontrol Noktalı Yarış, Hız Radarları, Drift.

- Oyunun kendisi: `app/src/main/assets/oyun/` (index.html, oyun.js, three.min.js)
- APK, GitHub Actions'taki "Zirve APK" işiyle oluşur; Artifacts → ZirveFestivali-APK.
- APK sabit bir imzayla (`app/imza.jks`) imzalanır: yeni sürümler eskisinin üzerine kurulur, rekorlar silinmez.

Modeller telefonda akıcı çalışsın diye sadeleştirilmiştir.
